# Security Policy

## Supported Versions

Security updates are applied to the latest stable release of MPD.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

If you discover a security vulnerability within MPD, please report it responsibly:

1. Do not create a public issue disclosing the vulnerability.
2. Open a Private Security Advisory on GitHub via the Security tab, or contact the project maintainers directly.
3. Include detailed reproduction steps, the affected versions/platforms, and any potential remediation suggestions.

All security reports are acknowledged within 48 hours, investigated promptly, and remediated in the next patch release.
